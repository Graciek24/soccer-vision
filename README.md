# Soccer Vision
A computer vision project that uses YOLO to detect players and objects in soccer footage.

## Current Progress

### Phase 1: Computer Vision
- [x] Set up Python environment
- [x] Integrated YOLO object detection
- [x] Processed soccer video footage
- [x] Detected players and sports balls
- [ ] Extract bounding box data
- [ ] Track players across frames
- [ ] Generate player movement analytics

### Technologies
- Python
- Ultralytics YOLO
- Open CV

## Goal
The goal of this project is to analyze soccer footage using computer vision and eventually turn player tracking data into useful sports analytics.
